# Installation

## Requirements

- Curiosity
- Willingness to ask questions
- That's it. Kayne has no other dependencies.

## Install

Kayne cannot be installed with a package manager. Installation is done in person:

```bash
# step 1: show up to a Cyber@Stout meeting
$ cd /cyber-stout/meetings

# step 2: say hi
$ echo "hi kayne"

# step 3: there is no step 3, he will take it from here
```

{: .tip }
Kayne will almost certainly say hi first. This is expected behavior.

## Verify the install

You'll know Kayne is installed correctly when:

- You feel noticeably more welcome
- You have a beginner friendly CTF challenge open
- Someone checks on you later to see how it's going
